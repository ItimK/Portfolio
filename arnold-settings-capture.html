Arnold Settings Capture Tool

November, 2025

Purpose

Developed a production pipeline tool for Autodesk Maya to address the time-consuming and error-prone process of manually documenting and comparing Arnold render settings across multiple iterations. This tool automates the entire process by directly querying Arnold's render node to extract technical parameters (sampling values, ray depths, and rendering configurations) and embedding them as formatted text overlays on rendered images.

Key Features

The installer will first automatically detect whether the required Pillow library is present and seamlessly installs it in the background if missing, eliminating manual setup steps for end users. Tool's features include a guided session mode that captures settings across multiple renders with automatic sequential numbering, a batch processor that generates comparison grids and an integrated file manager for cleaning up snapshot files and their associated JSON data.
