WinterScatter Tool

March, 2025

Inspiration

Harbin International Ice and Snow Sculpture Festival

Process

This project is a Python-driven Maya tool designed to streamline the creation of winter-themed scenes. All assets—trees, snowmen, lighting, and texturing—are procedurally generated through Python commands, with the ground being the only manually modeled element. By selecting points on any geometry and running the tool, artists can instantly place trees and snowmen in the scene. A custom UI allows users to choose the time of day (Day or Night), automatically applying the appropriate HDRI, select a color tone (Warm, Cool, or Mixed), and adjust the angle of the primary light source.
